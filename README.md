### Як запустити проєкти локально
1) **Клонувати репозиторій**
```bash
git clone https://github.com/0xVShO/Computer-Vision.git
```
2) **Перейти всередину монорепозиторію**
```bash
cd Computer-Vision
```
3) **Створіть та активуйте віртуальне середовище**

Для **Windows:**
```bash
python -m venv .venv
.venv/Scripts/Activate
```

Для **Linux / MacOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

4) **Встановіть відповідні залежності**
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

5) **Перейдіть до директорії відповідної лабораторної роботи та виконайте головний файл скрипта**
```bash
cd "[Назва директорії відповідної роботи]"
python main.py
```
